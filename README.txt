E-ARSIP KESBANGPOL KONAWE UTARA

CARA MENJALANKAN
1. Buka index.html dengan Chrome, Edge atau Firefox.
2. Klik Tambah Arsip, pilih kategori/subfolder/tahun, lalu unggah berkas.
3. Gunakan menu Cadangan / Pulihkan untuk membuat backup JSON secara berkala.

CATATAN PENTING
Ini adalah prototipe berjalan tanpa server, login, maupun sinkronisasi antarperangkat. Berkas disimpan di IndexedDB browser lokal. Penghapusan data browser dapat menghapus arsip. Tidak cocok untuk produksi ataupun dokumen rahasia/sensitif. Untuk penerapan instansi dibutuhkan server, autentikasi, hak akses, backup terenkripsi, audit log, keamanan unggahan dan retensi arsip.

Struktur kategori dan subfolder diambil dari file Excel lampiran.
